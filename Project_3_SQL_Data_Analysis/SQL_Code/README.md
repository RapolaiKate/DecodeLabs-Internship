# SQL Data Analysis Code

## 📊 Overview

This folder contains the SQL queries used to analyze the e-commerce dataset.

The queries were written in MySQL and focus on exploring order information, calculating sales metrics, analyzing products, and generating useful business insights from the dataset.

## 🔍 SQL Analysis Performed

The SQL queries cover the following analysis:

- Viewing sample records
- Filtering delivered orders
- Sorting orders by Total Price
- Counting orders by product
- Calculating total number of orders
- Calculating total sales
- Calculating total sales by product
- Calculating overall average order value
- Calculating average order value by product

## 📈 Key Metrics

The SQL analysis calculates important metrics such as:

- Total Orders
- Total Sales
- Average Order Value
- Number of Orders by Product
- Total Sales by Product
- Average Order Value by Product
