# Cleaned Dataset

## 📊 Overview

This folder contains the cleaned e-commerce dataset used for the SQL Data Analysis project.

The dataset contains **1,200 records** and was used to perform SQL queries and generate business insights from order, product, and sales information.

## 📁 Dataset Columns

The dataset contains the following fields:

- ID
- OrderID
- Date
- CustomerID
- Product
- Quantity
- UnitPrice
- ShippingAddress
- PaymentMethod
- OrderStatus
- TrackingNumber
- ItemsInCart
- CouponCode
- ReferralSource
- TotalPrice

## 🧹 Dataset Preparation

The dataset was prepared for SQL analysis by ensuring that:

- The dataset structure was suitable for database import.
- Column names were standardized for SQL use.
- Data types were reviewed.
- Unnecessary empty columns were removed.
- Numerical fields were checked for consistency.
- The dataset contained **1,200 records** after preparation.

## 🔍 Purpose

The cleaned dataset was imported into MySQL and used to perform SQL analysis, including:

- Total order calculations
- Total sales calculations
- Sales by product
- Number of orders by product
- Average order value
- Average order value by product
- Filtering and sorting transactions
