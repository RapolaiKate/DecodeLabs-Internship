# Project 2: Exploratory Data Analysis (EDA)

## Overview

This project was completed as part of the **DeCode Labs Data Analyst Internship**. The objective was to perform Exploratory Data Analysis (EDA) on an e-commerce dataset to understand its structure, identify patterns, and generate meaningful business insights.

## Objectives

* Explore the dataset and understand its structure.
* Check data quality and identify missing values.
* Analyze categorical and numerical variables.
* Visualize data using charts.
* Identify relationships between numerical variables.
* Summarize key findings and business insights.

## Tools & Technologies

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset Features

The dataset includes the following information:

* Order ID
* Date
* Customer ID
* Product
* Quantity
* Unit Price
* Shipping Address
* Payment Method
* Order Status
* Tracking Number
* Items in Cart
* Coupon Code
* Referral Source
* Total Price

## Exploratory Data Analysis

The following analyses were performed:

* Dataset overview
* Data information and summary statistics
* Missing value analysis
* Duplicate value check
* Categorical data analysis
* Product distribution analysis
* Order status analysis
* Payment method analysis
* Product revenue analysis
* Correlation analysis using a heatmap

## Key Insights

* Identified the most frequently purchased products.
* Analyzed customer order status distribution.
* Examined customer payment method preferences.
* Evaluated product revenue performance.
* Identified relationships between numerical variables using a correlation heatmap.

## Project Files

* `EDA.ipynb` – Complete Exploratory Data Analysis notebook.
* `ecommerce_dataset.xlsx` – Dataset used for the analysis.
* `screenshots/` – Visualizations and notebook screenshots.

## Conclusion

The Exploratory Data Analysis provided valuable insights into customer purchasing behaviour, product performance, payment preferences, and sales trends. The analysis demonstrates practical data analysis skills using Python and provides a solid foundation for further business intelligence and predictive analytics.
