# Project 3 – SQL Sales Analysis

## 📌 Project Overview

This project focuses on analyzing sales transaction data using **SQL**. The goal was to explore sales performance, product demand, order activity, and average order values to generate useful business insights.

## 🛠️ Tools Used

* MySQL
* SQL
* GitHub

## 📊 Dataset

The cleaned dataset contains **1,200 sales orders** across seven products:

* Chair
* Printer
* Laptop
* Tablet
* Monitor
* Desk
* Phone

Key fields analyzed include:

* Product
* Quantity
* UnitPrice
* TotalPrice
* OrderStatus

## 🔍 SQL Analysis

The analysis included:

* Reviewing sample sales transactions
* Filtering delivered orders
* Counting total orders
* Calculating total sales
* Calculating sales by product
* Comparing number of orders by product
* Calculating average order value by product

## 📈 Key Business Insights

* Total sales reached approximately **1,264,761.96** across **1,200 orders**.
* **Chairs** generated the highest total sales at **195,620.11**, closely followed by Printers and Laptops.
* **Printers** recorded the highest number of orders with **181**.
* **Laptops** had the highest average order value at approximately **1,110.56**.
* **Phones** recorded the lowest total sales and lowest average order value among the products analyzed.
* The business should maintain sufficient stock of high-performing products while using targeted promotions, bundling, and upselling strategies to improve lower-performing products.

## 💡 Business Recommendation

The business should prioritize **Chairs, Printers, and Laptops** because of their strong sales performance. At the same time, targeted marketing and promotional strategies could be used to improve the performance of **Phones** and increase their average order value.

## 🎯 Conclusion

This project demonstrates how SQL can be used to transform sales transaction data into meaningful business insights. The analysis provides a clear view of product performance, order volume, and revenue contribution, supporting data-driven business decisions.
