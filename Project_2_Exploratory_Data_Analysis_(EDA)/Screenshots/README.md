# EDA Screenshots

## 📊 Overview

This folder contains screenshots from the Exploratory Data Analysis (EDA) performed on the e-commerce dataset.

The screenshots provide visual evidence of the analysis, including data distributions, missing-value patterns, categorical analysis, numerical analysis, and identified patterns within the dataset.

## 📸 Screenshots Included

The screenshots demonstrate key parts of the EDA process, including:

- Dataset overview
- Data types and structure
- Missing-value analysis
- Product distribution
- Order-status distribution
- Payment-method distribution
- Coupon-code distribution
- Referral-source distribution
- Numerical analysis
- Outlier analysis
- Data visualizations

## 🎯 Purpose

The screenshots provide a visual reference for the analysis performed in the EDA notebook and help demonstrate the findings obtained during the exploratory analysis.

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
