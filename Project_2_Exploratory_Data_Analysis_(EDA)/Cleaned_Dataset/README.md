# Cleaned Dataset

## 📊 Overview

This folder contains the cleaned e-commerce dataset used for the Exploratory Data Analysis (EDA) project.

The dataset contains **1,200 records** and was prepared to provide a consistent and reliable dataset for exploratory analysis.

## 📁 Dataset Information

The dataset contains the following fields:

- ID
- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Shipping Address
- Payment Method
- Order Status
- Tracking Number
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

## 🧹 Dataset Preparation

The dataset was prepared by:

- Removing unnecessary empty columns.
- Reviewing missing values.
- Standardizing missing coupon-code values as `No Coupon`.
- Checking data types for date and numerical fields.
- Reviewing numerical values for consistency.
- Validating the relationship between Quantity, Unit Price, and Total Price.
- Reviewing potential outliers in Total Price.

## 📊 Dataset Summary

The cleaned dataset contains:

- **1,200 records**
- E-commerce order and transaction information
- Product and pricing information
- Customer and shipping information
- Payment and order-status information
- Coupon and referral information

## 🔍 Purpose

The cleaned dataset provides the foundation for exploring:

- Product distributions
- Order-status patterns
- Payment-method usage
- Coupon-code usage
- Referral sources
- Missing-value patterns
- Numerical distributions
- Potential outliers
