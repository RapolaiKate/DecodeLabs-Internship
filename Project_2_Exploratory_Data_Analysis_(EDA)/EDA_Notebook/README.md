# Exploratory Data Analysis Notebook

## 📊 Overview

This folder contains the Jupyter Notebook used to perform Exploratory Data Analysis (EDA) on the e-commerce dataset.

The notebook documents the process of exploring the dataset, identifying patterns, analyzing distributions, examining missing values, and investigating potential outliers.

## 🔍 Analysis Performed

The notebook includes:

- Dataset structure and dimensions
- Data type inspection
- Missing-value analysis
- Descriptive statistics
- Product distribution analysis
- Order-status analysis
- Payment-method analysis
- Coupon-code analysis
- Referral-source analysis
- Numerical data exploration
- Outlier detection using the IQR method
- Validation of potential Total Price outliers
- Data visualizations

## 📌 Key Findings

The analysis identified:

- **1,200 records** in the dataset.
- Printer had the highest product count with **181 records**.
- Cancelled was the most common order status with **250 records**.
- Online was the most common payment method with **258 records**.
- Instagram was the leading referral source with **259 records**.
- FreeShip was the most common coupon category with **330 records**.
- **8 potential Total Price outliers** were identified and validated.
