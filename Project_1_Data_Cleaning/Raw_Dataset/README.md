# Raw Dataset

## 📊 Overview

This folder contains the original raw dataset used for the Data Cleaning Report and Validation project.

The dataset is preserved in its original form to provide a clear reference point before any data cleaning, transformation, or validation was performed.

## 📁 Dataset Information

The dataset contains **1,200 e-commerce records** with the following fields:

- ID
- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Shipping Address
- Payment Method
- Order Status
- Tracking Number
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

## 🔍 Purpose

The raw dataset serves as the starting point for the data-cleaning process.

It was used to identify:

- Missing values
- Inconsistent data
- Data type issues
- Empty or unnecessary columns
- Potential data-quality problems
- Values requiring validation

## ⚠️ Important Note

This dataset has **not been cleaned or transformed**. It is retained in its original state for comparison with the cleaned dataset.
