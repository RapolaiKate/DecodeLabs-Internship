# Data Cleaning Report

## 📊 Overview

This folder contains the detailed data cleaning and validation report for the e-commerce dataset.

The report documents the data quality assessment, cleaning activities, validation checks, and final observations made during the data preparation process.

## 🎯 Purpose

The purpose of this report is to document how the raw dataset was assessed, cleaned, standardized, and validated to produce a reliable dataset suitable for analysis.

## 🧹 Data Cleaning Activities

The report covers the following activities:

- Dataset structure and column inspection
- Identification of missing values
- Removal of unnecessary and empty columns
- Data type validation
- Standardization of inconsistent values
- Review of duplicate records
- Numerical data validation
- Total Price validation
- Identification and review of potential outliers
- Final data quality checks

## 🔍 Validation

The dataset was validated by checking:

- Record count
- Column structure
- Data types
- Missing values
- Numerical consistency
- Quantity and Unit Price relationships
- Total Price calculations
- Standardized categorical values

Potential outliers in `Total Price` were reviewed against `Quantity × Unit Price` to determine whether they represented genuine values or data errors.

## 📈 Dataset

The dataset contains **1,200 e-commerce records** and includes information such as:

- Order details
- Customer information
- Products
- Quantity
- Unit Price
- Payment Method
- Order Status
- Coupon Code
- Referral Source
- Total Price
