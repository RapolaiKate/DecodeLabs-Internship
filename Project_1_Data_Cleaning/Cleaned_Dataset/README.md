# Cleaned Dataset

## 📊 Overview

This folder contains the cleaned and validated version of the original e-commerce dataset.

The dataset was processed to improve data quality, consistency, and reliability while preserving the information required for further analysis.

## 🧹 Cleaning Performed

The following data-cleaning activities were performed:

- Removed unnecessary and empty columns.
- Reviewed missing values across the dataset.
- Standardized missing coupon-code values to `No Coupon`.
- Validated date and numerical data types.
- Checked the consistency of Quantity, Unit Price, and Total Price.
- Reviewed potential outliers in Total Price.
- Performed data-quality and validation checks.

## 📁 Dataset Information

The cleaned dataset contains **1,200 e-commerce records** and includes fields such as:

- ID
- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Shipping Address
- Payment Method
- Order Status
- Tracking Number
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

## ✅ Validation

The cleaned dataset was validated to ensure that:

- The required columns were retained.
- Data types were appropriate.
- Numerical values were checked for consistency.
- Coupon-code values were standardized.
- Unnecessary columns were removed.
- The dataset remained suitable for analysis.

## 📌 Purpose

This cleaned dataset represents the final output of the data-cleaning and validation process and is ready for further analysis.
