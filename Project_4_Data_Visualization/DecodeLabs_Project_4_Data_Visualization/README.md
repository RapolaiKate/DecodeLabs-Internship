# Decode Labs Project 4 - Data Visualization

## 📊 Overview

This workbook contains the PivotTables and charts created for the Data Visualization project using an e-commerce sales dataset.

The workbook transforms the dataset into summarized views and visualizations to make sales and order patterns easier to understand.

## 📈 PivotTables and Charts

The workbook contains the following analyses:

### 1. Monthly Sales Trend

A line chart showing the monthly sales trend across the available data from 2023 to 2025.

### 2. Sales by Product

A chart comparing total sales across the different products:

- Chair
- Desk
- Laptop
- Monitor
- Phone
- Printer
- Tablet

### 3. Orders by Payment Method

A PivotTable and chart showing the number of orders by:

- Cash
- Credit Card
- Debit Card
- Gift Card
- Online

### 4. Orders by Status

A PivotTable and chart showing the number of orders by:

- Cancelled
- Delivered
- Pending
- Returned
- Shipped

## 📊 Key Results

### Sales by Product

| Product | Total Sales |
|---|---:|
| Chair | 195,620.11 |
| Printer | 195,612.61 |
| Laptop | 192,126.56 |
| Tablet | 186,568.95 |
| Monitor | 175,651.41 |
| Desk | 167,459.93 |
| Phone | 151,722.39 |

**Chair** recorded the highest total sales, closely followed by **Printer**.

### Orders by Payment Method

| Payment Method | Orders |
|---|---:|
| Online | 258 |
| Cash | 246 |
| Credit Card | 234 |
| Debit Card | 232 |
| Gift Card | 230 |

**Online** was the most frequently used payment method.

### Orders by Status

| Order Status | Orders |
|---|---:|
| Cancelled | 250 |
| Returned | 247 |
| Pending | 237 |
| Shipped | 235 |
| Delivered | 231 |

**Cancelled** orders had the highest number of records.
