# Cleaned Dataset

## 📊 Overview

This folder contains the cleaned e-commerce dataset used to create the PivotTables and visualizations for the Data Visualization project.

The dataset provides the underlying data used to analyze sales trends, product performance, payment methods, and order statuses.

## 📁 Dataset Information

The dataset contains e-commerce transaction and order information, including:

- ID
- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Shipping Address
- Payment Method
- Order Status
- Tracking Number
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

## 🧹 Dataset Preparation

The dataset was prepared for visualization by:

- Removing unnecessary columns.
- Reviewing data types.
- Checking the dataset structure.
- Reviewing missing values.
- Standardizing relevant categorical values.
- Ensuring numerical fields were suitable for analysis.
- Preparing the dataset for Excel PivotTables and charts.

## 📊 Purpose

The cleaned dataset was used as the source data for:

- Monthly Sales Trend
- Sales by Product
- Orders by Payment Method
- Orders by Order Status
